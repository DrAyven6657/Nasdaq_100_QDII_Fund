# 纳指100 / 标普500 QDII 基金 · 场外额度监控

一个零成本、无需服务器的静态网页，每日自动更新，用于监控**纳斯达克100 / 标普500 / 纳指科技 QDII 基金（场外 A 类份额）**的申购状态与限购额度。

## 🔗 在线访问（GitHub Pages）

**https://drayven6657.github.io/Nasdaq_100_QDII_Fund/**

无需安装任何东西，打开即用。数据由 GitHub Actions 每日自动抓取提交，页面永远展示最新结果。

## 功能一览

- **申购额度监控**：场外 A 类份额的申购状态（开放申购 / 限大额 / 暂停申购 / 暂不销售）+ 第三方代销渠道的单日限购金额
- **净值与收益**：单位净值、净值日期、近 1 年收益率（官方复权口径，带同指数基金横向对比进度条）
- **费率与误差**：管理费 + 托管费（年）、申购费优惠费率、年化跟踪误差
- **指数实时行情**：纳指100 / 标普500 实时点位与涨跌卡片，跟随指数筛选联动
- **指数日 K 线**：基于 Apache ECharts（本地化内置，无 CDN 依赖）绘制蜡烛图 + MA5/10/20 均线 + 成交量副图，支持 8 档时间区间切换、鼠标滚轮 / 底部滑杆拖拽缩放、悬停十字光标查看开高低收
- **筛选与排序**：按指数筛选分组（纳指100 / 标普500 / 纳指科技），全部数值列可排序，可一键「可申购优先」
- **每日自动更新**：GitHub Actions 每天北京时间 04:05 / 16:05 各抓取一次，自动提交数据并同步到 GitHub Pages

## 本地运行

### Windows 双击即用

双击 **`启动.bat`**，会自动更新数据并在浏览器里打开最新结果。之后每天想看，双击一次即可。

### 手动方式（Windows / Mac / Linux 通用）

```bash
python scrape.py      # 抓取数据，生成 data.json / data.js / kline_data.js
```

然后用浏览器打开 `index.html` 即可。数据与 ECharts 库均通过本地 `<script>` 方式加载，
`file://` 协议下也能正常显示，无需本地 HTTP 服务，也不依赖任何网络 CDN。

本地抓到的只是快照；要获得「每天自动更新」的效果，把仓库 Fork 后开启 GitHub Actions 与 GitHub Pages 即可（Actions 会每天自动抓取并提交数据）。

## 维护基金清单

编辑 `scrape.py` 顶部的 `FUNDS` 列表即可增删基金（仅收录 A 类份额，C/D/E/F/I 类已剔除），格式：

```python
FUNDS = [
    ("270042", None, "场外", "纳指100", "广发基金"),   # (代码, 市场, 类型, 指数, 公司)
]
```

- 代码：天天基金 6 位基金代码
- 市场：`sh` 沪市 / `sz` 深市 / `None` 场外
- 类型：`ETF` / `LOF` / `场外`
- 指数：`纳指100` / `标普500` / `纳指科技`
- 公司：基金公司简称

## 数据口径说明（重要）

- **QDII 净值为滞后净值**（T+1 甚至 T+2，因美股收盘在 A 股次日凌晨），请勿当作实时估值。
- **代销额度** = 天天基金等第三方渠道的单日限购金额，来自基金详情页，随公告每日更新。
  暂停申购 / 暂不销售的基金会清空残留的旧额度（避免误导），并且前者不显示限购金额。
- **近 1 年收益率**优先取天天基金官方字段（已复权、含分红再投）；缺失时依次回退到
  累计净值走势、单位净值走势计算。不能用单位净值直算——分红 / 份额折算会把收益算成大幅亏损。
- **稳健兜底**：个别字段抓取失败时，自动沿用上一次成功的数据补齐，避免某列整列空白；
  指数日 K 抓取全部失败时，保留旧的 `kline_data.js`。
- **长历史性能**：日 K 超过 1000 个数据点时自动按区间聚合（保留首开 / 末收 / 最高 / 最低 / 成交量合计），保证「成立来」等超长区间渲染流畅。
