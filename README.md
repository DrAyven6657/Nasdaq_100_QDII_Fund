# 行情监控 · 场外额度监控

一个**零成本、无需服务器**的静态网页：监控纳斯达克100 / 标普500 / 纳指科技 QDII 基金（场外 A 类）的申购状态与限购额度，内置四大指数（纳指100 / 标普500 / 上证指数 / 创业板指）实时行情卡与同花顺式分时图、三十年级别的指数日 K 复盘与历史定投回测。浅色简洁界面，每日定时自动更新，数据抓取纯 Python 标准库实现。

> 🌐 **在线访问（GitHub Pages）：[https://drayven6657.github.io/Nasdaq_100_QDII_Fund/](https://drayven6657.github.io/Nasdaq_100_QDII_Fund/)**
>
> 无需安装任何东西，打开即用。数据由 GitHub Actions 每日定时抓取提交，页面永远展示最新结果。

## ✨ 功能一览

**① 基金额度监控（主页表格）**

- **申购状态监控**：场外 A 类份额的申购状态（开放申购 / 限大额 / 暂停申购 / 暂不销售）+ 第三方代销渠道的单日限购金额
- **净值与收益**：单位净值、净值日期、近 1 年收益率（官方复权口径，带同指数基金横向对比进度条）
- **费率与误差**：管理费 + 托管费（年）、申购费优惠费率、年化跟踪误差
- **筛选与排序**：按指数筛选分组，全部数值列可排序，可一键「可申购优先」；手机端自动切卡片式布局

**② 指数行情卡 · 实时 + 分时（纳指100 / 标普500 / 上证指数 / 创业板指，2×2 排布）**

- **实时点位**：开市期间每 3 秒轮询一次真实时报价，点数恒为黑色、涨跌额与涨跌幅红涨绿跌，不随行情闪烁变色
- **实时 / 收盘角标**：按交易时段自动判定——美股开市（美东 09:30–16:00，夏令时/冬令时自动换算为北京时间）显示绿色「实时 HH:MM」；收盘、周末休市、A 股午休（11:30–13:00）显示灰色「收盘 HH:MM」，并自动停止轮询省流量；角标时间一律显示当前实际时刻（北京时间，收市后同样走表），美股卡片并在角标旁附当前对应的纽约时间（夏令时/冬令时自动正确）
- **同花顺式分时图**：右侧迷你分时线按**全天固定时间槽**绘制（美股 390 分钟、A 股 240 分钟，A 股午休自然压缩），开盘后每分钟推进一格、**永不缩放**；底部三枚时间刻度按北京时间标注，跨夏令时自动换算（如美东 09:30 夏令时显示 21:30、冬令时显示 22:30）；曲线最右端「当前分钟」点位随实时报价同步伸缩（只改值不加坑），爆拉 / 跳水时数秒内跟上，整分钟后由正式分钟点自然替换
- **昨收基准线**：灰色虚线标注昨日收盘价，位于曲线与昨收构成的真实落点（同花顺同款口径）；**现价跌破昨收整条线变绿、收复则变红**，虚线下方带渐变填充
- **断源自愈**：A 股分时走腾讯直连（主源）、东财经 Cloudflare 兜底（偶发 520 时保留上一帧画面，每 60 秒自动补拉新点）；页面重新打开时先用本地静态分时兜底渲染

**③ 指数日 K 复盘**

- **全历史日 K 线**（主页「纳指100 / 标普500」页签 + 独立页面 [kline.html](kline.html)）：ECharts 蜡烛图 + MA5/20/50/200 四条均线 + 成交量副图；纳指100 自 2001 年、标普500 自 1986 年，8 档区间切换、滚轮/滑杆缩放、悬停查看开高低收与振幅；图头实时显示最新价、涨跌与各均线数值

**④ 历史定投回测（[dca.html](dca.html)）**

- 覆盖**纳斯达克100 / 标普500 / 上证指数 / 红利低波50**（上证自 1990 年；红利低波50 为南方标普中国A股大盘红利低波50ETF联接A（008163），自 2020-01 起按基金净值回测，分红方式可选），任意金额、每日 / 每周 / 每两周 / 每月频率、任意扣款日（休市自动顺延）、任意起止年份
- 输出累计投入、期末资产、累计收益率、资金加权年化（IRR）、持仓最大回撤，图表叠加**「假如起点一次全买」**对照曲线（同样的钱第一天全买的假想收益，用于对比分批建仓），指标数字带进场动画

## 🏗 整体架构

本项目是「**静态前端 + Serverless 数据代理 + 定时抓取**」三件套，全程零服务器租用成本：

| 角色 | 载体 | 职责 |
|---|---|---|
| 前端托管 | GitHub Pages | 页面、样式、图表渲染全部在访客浏览器本地完成 |
| 实时代理 | Cloudflare Worker（Serverless 函数） | 唯一在服务器上运行的代码：绕过跨域限制代取新浪/东财行情，无状态、无数据库、纯转发 |
| 定时抓取 | GitHub Actions | 每天北京时间 06:00 / 16:00 自动运行抓取脚本，把新数据提交进仓库 |
| 手动入口 | 本机 `启动.bat` / `scrape.py` | 随时双击立即更新一次数据并打开页面 |

Worker 供四条路由：根路由转发新浪实时行情（GBK 原样返回 + 跨域头）、`/kline` 转发日 K 数据（新浪 / 新浪美股 / 东财，东财侧带代码白名单）、`/trends` 转发东财分时数据、`/tminute` 转发腾讯 A 股分钟线（分时主源，实测最稳）。

> **更换 Worker 域名只需改两处**：`kline_data.py` 顶部的 `WORKER_HOST` 与 `index.html` 内的 `RT_PROXY`（抓取脚本复用前者的常量），其余代码零改动。

把仓库 Fork 后开启 GitHub Actions 与 GitHub Pages 即可：Actions 每天定时抓取并提交数据，GitHub Pages 同步展示最新页面。

## ⏰ 每日定时自动更新（基金净值 / 指数行情）

`.github/workflows/update.yml` 在每天**北京时间 06:00**（美股收盘后，当日完整日 K 已出）与 **16:00**（A 股收盘后，当日净值更新）各触发一次：

1. 运行 `python scrape.py` 抓取全部 22 只基金的净值 / 申购状态 / 限购额度 + 三大指数日 K 与四大指数分时快照；
2. 将更新后的 `data.json / data.js / kline_data.js` 提交进仓库，GitHub Pages 随之展示最新数据。

> GitHub 的定时任务为「尽力而为」：整点高峰期可能延迟数小时、极少数情况下被丢弃，属正常现象，数据在下一次触发时自动补齐。

## 📐 数据口径说明（重要）

- **QDII 净值为滞后净值**（T+1 甚至 T+2，因美股收盘在 A 股次日凌晨），请勿当作实时估值。
- **代销额度** = 天天基金等第三方渠道的单日限购金额，来自基金详情页，随公告每日更新。暂停申购 / 暂不销售的基金会清空残留的旧额度（避免误导），并且前者不显示限购金额。
- **近 1 年收益率**优先取天天基金官方字段（已复权、含分红再投）；缺失时依次回退到累计净值走势、单位净值走势计算。不能用单位净值直算——分红 / 份额折算会把收益算成大幅亏损。
- **均线口径**：MA 均线按全部历史收盘价计算后再截取显示（而非仅在当前视图内计算），因此「近1月」等短区间下 MA50 / MA200 也完整可见。
- **纳指100 历史拼接**：新浪美股真指数 `.ndx` 仅收录 2014-02-18 之后，更早段用 Invesco QQQ（跟踪纳指100 的 ETF）的前复权价按「接缝比例」整体折算后拼接——接缝日 2014-02-18 处「QQQ 末日折算收盘 = 指数首日开盘」，序列零跳变；比例每日按两侧重叠末日重算，QQQ 抓取失败时自动沿用旧拼接前缀。拼接段仅作长期趋势参考（成交量口径不同），页面上有灰色小字注明。
- **纳指100 分时口径**：纳指100 指数本身无免费分钟级数据源，分时以 Invesco QQQ（105.QQQ）分钟线代替——当日走势与指数高度一致；昨收基准同样取 QQQ 自己的昨日收盘（与分钟线同量纲，避免高度压扁）。标普500 / 上证指数 / 创业板指分时走东财原版接口，昨收 = 快照点位 − 涨跌额。迷你图仅用于看形态，不展示数值。
- **行情卡配色口径**：点数恒为黑色、卡片恒为白底，颜色只由「现价 vs 昨日收盘」决定分时线红绿与涨跌幅红绿，杜绝「涨跌与线颜色打架」的歧义。
- **实时链路自愈**：A 股分时主源为腾讯直连（实测最稳），东财接口经 Cloudflare 代理作为兜底、存在间歇性 520；页面侧每 60 秒自动补帧、失败保留上一帧；抓取侧按 6 次 × 2 秒重试，仍失败则沿用上一次成功的数据，页面不会开天窗。
- **定投回测口径**：以指数收盘价序列构造「期初 = 1」的累计倍数计算各期成本与市值；指数价格不含成分股股息，与真实基金收益存在小幅口径差（股息再投为正贡献、费用为负贡献）；资金加权年化收益率（IRR）按实际扣款日期折现、二分法求根。红利低波50 选项按南方红利低波50联接A（008163）的基金净值回测（已扣管理托管费、未计申购费），**分红方式可选**：红利再投资按复权净值口径（从天天基金 pingzhongdata 的单位净值 + 累计净值双序列反推每份分红，分红 = 累计净值差 − 单位净值差，足额分红远大于小数舍入噪声）；现金分红按单位净值 + 分红事件表模拟（kline_data.js 额外输出 `DCA_FUND_META`：现金按在册份额折现入池、不再生息，期末资产 = 持仓净值 + 现金池）。两种口径实测相差 11 个百分点左右（2020-2026，再投占优），页面上可一键切换对比。

## 🛠 技术实现要点

- **纯静态零依赖**：前端原生 HTML + CSS + JavaScript；图表使用 Apache ECharts 5（Apache-2.0 协议），已内置为仓库内 `echarts.min.js`，离线可用、不依赖 CDN，`file://` 直开与 GitHub Pages 均适用。
- **图表库秒开缓存**：`echarts.min.js`（约 1MB）首次加载后由页面脚本存入访客 `localStorage`（缓存键随版本号，如 `echarts.cache.5.5.1`），次日及以后直接本地注入、不再发起网络请求；升级库版本时改缓存键即自动失效，隐私模式等不支持 localStorage 的环境自动回退正常加载（缓存逻辑内置于三个页面，无独立脚本文件）。
- **双频轮询与开市判定**：页面打开后由实时插件按市场接管——开市时段每 3 秒拉一次报价、每 60 秒补一次分时；周末 / 夜盘 / A 股午休自动停止轮询并显示「收盘」角标；美东时段判定内置夏令时换算（`Intl` 时区偏移反解，无手工开关）。
- **K 线数据瘦身**：`kline_data.js` 中的行情行采用 `[日期, 开, 收, 高, 低, 量]` 紧凑数组格式（较对象格式体积减少约 30%），前端读取时归一化并按指数缓存；旧版对象格式仍可被识别，保证缓存与备份互相兼容。
- **均线配置化**：K 线渲染模块内的均线（数量 / 周期 / 颜色）以配置表驱动，绘图、图例数值、悬停提示、区间切片全自动遍历，增删一条均线只需改一行配置。
- **长历史性能**：日 K 超过 1000 个数据点时自动按区间聚合（保留首开 / 末收 / 最高 / 最低 / 成交量合计），保证「成立来」等超长区间渲染流畅。
- **移动端适配**：屏宽 ≤720px 时额度表自动切换为卡片式列表（表头隐藏、字段名内联标注），行情卡 / 分时图 / K 线图自适应窄屏，无横向滚动。
- **稳健兜底**：任一数据接口抓取失败时自动沿用上一次成功的数据补齐；静态快照（腾讯）负责「页面打开瞬间的兜底点位」，实时链路（新浪/东财经 Worker）负责盘中刷新，两层互为备份。
