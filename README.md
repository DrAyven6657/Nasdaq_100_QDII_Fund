# 纳指100 / 标普500 QDII 基金 · 场外额度监控

一个**零成本、无需服务器**的静态网页：监控纳斯达克100 / 标普500 / 纳指科技 QDII 基金（场外 A 类）的申购状态与限购额度，内置指数实时行情、估值风险条、三十年级别的指数日 K 复盘与历史定投回测。浅色简洁界面，每日自动更新，数据抓取纯 Python 标准库实现。

> 🌐 **在线访问（GitHub Pages）：[https://drayven6657.github.io/Nasdaq_100_QDII_Fund/](https://drayven6657.github.io/Nasdaq_100_QDII_Fund/)**
>
> 无需安装任何东西，打开即用。数据由 GitHub Actions 每日自动抓取提交，页面永远展示最新结果。

## ✨ 功能一览

**① 基金额度监控（主页表格）**

- **申购状态监控**：场外 A 类份额的申购状态（开放申购 / 限大额 / 暂停申购 / 暂不销售）+ 第三方代销渠道的单日限购金额
- **净值与收益**：单位净值、净值日期、近 1 年收益率（官方复权口径，带同指数基金横向对比进度条）
- **费率与误差**：管理费 + 托管费（年）、申购费优惠费率、年化跟踪误差
- **筛选与排序**：按指数筛选分组，全部数值列可排序，可一键「可申购优先」；手机端自动切卡片式布局

**② 指数行情与趋势复盘**

- **实时行情卡**：纳指100 / 标普500 实时点位与涨跌，右侧附 66 日迷你走势线（sparkline），随指数筛选联动
- **估值风险条**：两指数的成分股整体 PE（TTM）与**近 10 年 PE 历史分位**，五档渐变横条（极度低估 → 极度高估）+ 分位指针；按顶部「指数」筛选联动显示
- **全历史日 K 线**：ECharts 绘制蜡烛图 + MA5/20/50/200 四条均线 + 成交量副图；纳指100 自 2001 年、标普500 自 1986 年，8 档区间切换、滚轮/滑杆缩放、悬停查看开高低收与振幅；图头实时显示最新价、涨跌与各均线数值

**③ 历史定投回测（[dca.html](dca.html)）**

- 覆盖**纳斯达克100 / 标普500 / 上证指数**（上证自 1990 年），任意金额、每日 / 每周 / 每两周 / 每月频率、任意扣款日（休市自动顺延）、任意起止年份
- 输出累计投入、期末资产、累计收益率、资金加权年化（IRR）、持仓最大回撤，图表叠加**「假如起点一次全买」**对照曲线（同样的钱第一天全买的假想收益，用于对比分批建仓），指标数字带进场动画

## 🚀 快速开始

### 方式一：在线版（推荐）

直接打开 **[https://drayven6657.github.io/Nasdaq_100_QDII_Fund/](https://drayven6657.github.io/Nasdaq_100_QDII_Fund/)**，什么都不用装。

### 方式二：本地使用（Windows）

双击 **`启动.bat`**：自动更新数据并在浏览器里打开最新结果。

或者手动运行：

```bash
python scrape.py      # 抓取数据，生成 data.json / data.js / kline_data.js / pe_data.js
```

然后用浏览器打开 `index.html` 即可。数据与 ECharts 库均通过本地 `<script>` 方式加载，`file://` 协议下也能正常显示，无需本地 HTTP 服务，也不依赖任何网络 CDN。

### 方式三：部署到自己的 GitHub Pages

把仓库 Fork 后开启 GitHub Actions 与 GitHub Pages 即可：Actions 每天自动抓取并提交数据，GitHub Pages 同步展示最新页面。

## ⏰ 每日自动更新机制

`.github/workflows/update.yml` 在每天**北京时间 06:00**（美股收盘后，当日完整日K已出）与 **16:00**（A 股收盘后）各触发一次：

1. 运行 `python scrape.py` 抓取全部 22 只基金 + 三大指数日 K + 指数估值；
2. 将更新后的 `data.json / data.js / kline_data.js / pe_data.js` 提交进仓库，GitHub Pages 随之展示最新数据。

> GitHub 的定时任务为"尽力而为"：整点高峰期可能延迟数小时、极少数情况下被丢弃，属正常现象，数据在下一次触发时自动补齐。

## 📐 数据口径说明（重要）

- **QDII 净值为滞后净值**（T+1 甚至 T+2，因美股收盘在 A 股次日凌晨），请勿当作实时估值。
- **代销额度** = 天天基金等第三方渠道的单日限购金额，来自基金详情页，随公告每日更新。暂停申购 / 暂不销售的基金会清空残留的旧额度（避免误导），并且前者不显示限购金额。
- **近 1 年收益率**优先取天天基金官方字段（已复权、含分红再投）；缺失时依次回退到累计净值走势、单位净值走势计算。不能用单位净值直算——分红 / 份额折算会把收益算成大幅亏损。
- **估值分位口径**：PE 为指数成分股整体市盈率（TTM，市值加权），分位为当前 PE 在自身近 10 年历史中的百分位（蛋卷基金口径）。风险五档按**分位**划定而非 PE 绝对值——不同指数盈利结构不同（成长占主的纳指100 天然比标普500 贵），PE 绝对值横向比较意义不大。
- **均线口径**：MA 均线按全部历史收盘价计算后再截取显示（而非仅在当前视图内计算），因此「近1月」等短区间下 MA50 / MA200 也完整可见。
- **稳健兜底**：个别字段抓取失败时自动沿用上一次成功的数据补齐；指数日 K 失败保留旧 `kline_data.js`；指数估值失败保留旧 `pe_data.js`，页面不会开天窗。
- **长历史性能**：日 K 超过 1000 个数据点时自动按区间聚合（保留首开 / 末收 / 最高 / 最低 / 成交量合计），保证「成立来」等超长区间渲染流畅。
- **纳指100 历史拼接**：东财的纳指100 指数日线仅收录 2019-04-08 之后，更早段用 Invesco QQQ（跟踪纳指100 的 ETF）的前复权价按「接缝比例」整体折算后拼接——接缝日 2019-04-08 处「QQQ 末日折算收盘 = 指数首日开盘」，序列零跳变；拼接段仅作长期趋势参考（成交量口径不同），页面上有灰色小字注明。拼接每天自动重建，QQQ 偶发抓取失败时自动沿用旧拼接前缀。
- **定投回测口径**：以指数收盘价序列构造「期初 = 1」的累计倍数计算各期成本与市值；指数价格不含成分股股息，与真实基金收益存在小幅口径差（股息再投为正贡献、费用为负贡献）；资金加权年化收益率（IRR）按实际扣款日期折现、二分法求根。

## 🛠 技术实现要点

- **纯静态零依赖**：前端原生 HTML + CSS + JavaScript；图表使用 Apache ECharts 5（Apache-2.0 协议），已内置为仓库内 `echarts.min.js`，离线可用、不依赖 CDN，GitHub Pages 同样适用。
- **图表库秒开缓存**：`echarts.min.js`（约 1MB）首次加载后存入访客 `localStorage`，次日及以后直接从本地注入脚本，不再发起网络请求；库升级时按版本号更换缓存键即可自动失效。隐私模式等不支持 localStorage 的环境自动回退到正常加载。
- **K 线数据瘦身**：`kline_data.js` 中的行情行采用 `[日期, 开, 收, 高, 低, 量]` 紧凑数组格式（较对象格式体积减少约 30%），前端读取时归一化并按指数缓存；旧版对象格式仍可被识别，保证缓存与备份互相兼容。
- **均线配置化**：K 线渲染模块内的均线（数量 / 周期 / 颜色）以配置表驱动，绘图、图例数值、悬停提示、区间切片全自动遍历，增删一条均线只需改一行配置。
- **移动端适配**：屏宽 ≤720px 时额度表自动切换为卡片式列表（表头隐藏、字段名内联标注），K 线图、行情卡与估值风险条自适应窄屏，无横向滚动。

## 🔧 维护基金清单

编辑 `scrape.py` 顶部的 `FUNDS` 列表即可增删基金（仅收录 A 类份额，C/D/E/F/I 类已剔除），格式：

```python
FUNDS = [
    ("270042", None, "场外", "纳指100", "广发基金"),   # (代码, 市场, 类型, 指数, 公司)
]
```

- 代码：天天基金 6 位基金代码
- 市场：`sh` 沪市 / `sz` 深市 / `None` 场外
- 类型：`ETF` / `LOF` / `场外`
- 指数：`纳指100` / `标普500` / `纳指科技`
- 公司：基金公司简称
